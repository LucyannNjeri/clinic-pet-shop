🐾 Happy Paws — Pet Care & Wellness Platform

A modern pet care web application that connects pet owners to veterinary services, grooming, training, and pet wellness resources — all in one place.

🚀 Live Demo
https://lucyannnjeri.github.io/clinic-pet-shop/

📌 About the Project:

Happy Paws is a frontend pet care platform designed to simulate a real-world veterinary and pet services system.
It allows users to explore services, learn about pet care, view veterinary professionals, and interact with a clean, responsive UI experience.

This project was built to strengthen my skills in:

- HTML structure & semantic layout
- Advanced CSS styling & responsive design
- JavaScript DOM manipulation
- UI animations and user experience design
✨ Features:
- 🏥 Pet wellness service listings (vet care, grooming, training)
- 📊 Animated statistics counter
- 🎥 Interactive video play/pause feature
- 🧑‍⚕️ Veterinary doctor profiles section
- 💬 Testimonials section
- 📱 Fully responsive design (mobile + desktop)
- 🎨 Smooth UI interactions and hover effects

🛠️ Built With:

- HTML5
- CSS3 (Flexbox + Grid)
- JavaScript
- AOS (Animate On Scroll Library)
- Font Awesome Icons

While building this project, I improved my understanding of:

- Structuring large frontend layouts
- Creating reusable UI components
- Handling animations without hurting performance
- Improving page load optimization
- Writing cleaner, more maintainable code
- Performance Improvements (v2)

This project was later optimized to improve performance:

- Reduced heavy animations
- Fixed CSS structure issues (removed invalid nesting)
- Added lazy loading for images
- Optimized JavaScript counter logic
- Improved page load speed
